1 VS Code Live Server

Самый простой способ!

  • Откройте index.html в VS Code
  • Нажмите правой кнопкой → Open with Live Server
  • Автоматически откроется в браузере на http://127.0.0.1:5500
2 Обычный браузер

Альтернативный способ

  • Откройте папку проекта в файловом менеджере
  • Дважды нажмите на index.html
  • Браузер откроет главную страницу
  • Все функции работают, кроме скачивания XML
3 Установить Live Server расширение

Если Live Server еще не установлен:

  • Откройте VS Code
  • Нажмите Ctrl+Shift+X
  • Найдите "Live Server" от Ritwick Dey
  • Нажмите "Install"
  • Перезагрузите VS Code

🏛️ Паттерн Visitor в проекте

Проект использует паттерн Visitor для экспорта товаров в XML. Это продемонстрирует, как правильно разделять логику обработки от структуры данных.

Попробуйте сами:
  1. Откройте главную страницу
  2. Найдите секцию "Паттерн Visitor"
  3. Нажмите кнопку "Экспортировать товары в XML"
  4. Увидите XML код всех товаров
  5. Скачайте XML файл

Подробное объяснение: Откройте файл VISITOR_PATTERN_EXPLANATION.js для полного разбора паттерна.

💡 Полезные советы

  • Разработчик: Нажмите F12 для открытия DevTools, там можно смотреть консоль
  • localStorage: Корзина сохраняется в браузере, очистите кэш чтобы сбросить
  • XML: Нажмите кнопку экспорта на главной для демонстрации Visitor паттерна
  • Мобильный: Откройте на смартфоне через тот же http://127.0.0.1:5500
