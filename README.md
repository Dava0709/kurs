# 💪 IronPower Store - Интернет-магазин спортивного питания

## Полное описание проекта

Это полностью функциональный учебный веб-проект интернет-магазина спортивного питания, созданный с использованием **чистого JavaScript** (без фреймворков), HTML5 и CSS3.

Проект **реализует паттерн проектирования Visitor** для демонстрации правильной архитектуры и разделения ответственности при работе с объектами.

## 🚀 Как запустить проект

### Вариант 1: VS Code Live Server (РЕКОМЕНДУЕТСЯ)

1. **Откройте проект в VS Code:**
   ```bash
   code c:\Users\User\Desktop\курсовая\IronPower-Store
   ```

2. **Установите расширение Live Server** (если еще не установлено):
   - Откройте Extensions (Ctrl+Shift+X)
   - Найдите "Live Server" от Ritwick Dey
   - Нажмите "Install"

3. **Запустите Live Server:**
   - Щелкните правой кнопкой на `index.html`
   - Выберите "Open with Live Server"
   - Откроется `http://127.0.0.1:5500`

### Вариант 2: Простой запуск

- Просто откройте `index.html` в браузере (двойной клик)
- Все функции будут работать, кроме экспорта в XML (нужна локальная доставка)

## 🏛️ Паттерн Visitor - Подробное объяснение

### Что это?

**Visitor** - это паттерн проектирования, который позволяет определить новую операцию без изменения классов элементов, над которыми эта операция проводится.

### Проблема, которую решает

❌ **Без Visitor (плохо):**
```javascript
class Product {
  // Много методов в одном классе
  exportToXML() { /* ... */ }
  exportToJSON() { /* ... */ }
  exportToCSV() { /* ... */ }
  sendByEmail() { /* ... */ }
  printReceipt() { /* ... */ }
}
// Класс становится толстым и сложным!
```

✅ **С Visitor (хорошо):**
```javascript
class Product {
  // Только основные данные
  accept(visitor) {
    return visitor.visit(this);
  }
}

class XMLExportVisitor {
  visit(product) {
    return /* XML */;
  }
}
```

### Как работает в нашем проекте

#### 1. Определяем Visitor интерфейс

```javascript
class Visitor {
  visit(product) {
    throw new Error('Должен быть переопределен');
  }
}
```

#### 2. Создаем конкретные Visitor'ы

```javascript
class XMLExportVisitor extends Visitor {
  visit(product) {
    // Получаем данные товара
    const data = product.getData();
    // Формируем XML
    return this.generateProductXML(data);
  }
}
```

#### 3. Товары содержат метод accept()

```javascript
class Product {
  accept(visitor) {
    return visitor.visit(this);  // Visitor обрабатывает товар
  }
}
```

#### 4. Использование

```javascript
// Создаем visitor
const xmlVisitor = new XMLExportVisitor();

// Экспортируем товары
const xmlContent = xmlVisitor.exportProducts(allProducts);
```

### Ключевые моменты в коде

Поиск `// ===== VISITOR PATTERN START =====` в файлах:

- **js/products.js** - определения классов товаров
- **js/visitor.js** - реализация visitor'ов
- **js/app.js** - использование visitor'ов
- **index.html** - демонстрация для пользователя

## 🎓 Преимущества паттерна Visitor

### ✅ Разделение ответственности
- Товар отвечает за данные
- Visitor отвечает за обработку
- Каждый класс имеет одну ответственность

### ✅ Легко добавлять новые операции
```javascript
// Просто создаем новый Visitor!
class PDFExportVisitor extends Visitor {
  visit(product) {
    // Новая логика экспорта в PDF
  }
}
```

### ✅ Безопасность типов
- TypeScript-подобная типизация через структуру
- Все visitor'ы имеют одинаковый интерфейс

### ✅ Гибкость
- Можно применять разные visitor'ы к одним объектам
- Новые операции не влияют на старый код

### ✅ Легче тестировать
- Каждый visitor можно тестировать отдельно
- Товары остаются простыми и тестируемыми

## 💾 Хранение данных

### localStorage

Корзина сохраняется в браузере:

```javascript
// Сохранение
localStorage.setItem('ironpowerCart', JSON.stringify(cart));

// Загрузка
const cart = JSON.parse(localStorage.getItem('ironpowerCart'));
```

Это позволяет:
- Сохранить товары при закрытии браузера
- Быстро загружать корзину
- Не требует бэкенда

## ❓ Часто задаваемые вопросы

### Q: Почему используется localStorage?
A: Для простоты и отсутствия требований к бэкенду. В реальном приложении используется база данных.

### Q: Можно ли добавить аутентификацию?
A: Да, добавив простую систему с localStorage или подключив API.

### Q: Как добавить новый товар?
A: Создайте класс, наследующий Product, и добавьте в getAllProducts().

### Q: Как работает адаптивность?
A: Используются media queries в CSS для разных размеров экрана.

### Q: Почему нет фреймворков?
A: Это помогает лучше понять фундаментальные концепции JavaScript и паттерны.
