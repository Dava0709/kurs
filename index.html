Паттерн Visitor

Экспортируйте каталог товаров в XML с помощью паттерна Visitor

Паттерн Visitor позволяет выполнять операции над объектами товаров без изменения их классов.
Нажмите кнопку ниже, чтобы экспортировать все товары в XML формат.

Как это работает:
1. Product (товар) имеет метод accept(visitor)
2. Visitor (XMLExportVisitor) содержит логику экспорта
3. При вызове product.accept(xmlVisitor) товар передает себя visitor'у
4. Visitor получает доступ к данным и формирует XML
5. Логика обработки отделена от структуры данных
